# TheMindShift Writer Loop

Use this skill to turn approved research synthesis into a draft that follows the current TheMindShift issue spine. It is not a generic newsletter writer.

TheMindShift project files and `TheAngry_Editor-inChief` remain authority. This skill is procedural support for a repeated editorial loop.

## Required Reads

1. Read TheMindShift `AGENTS.md`, `ACTIVE_STATE.md`, `NEWSLETTER_DOCTRINE.md`, `MODES/writer-loop.md` if present, and the issue template.
2. Read the approved research synthesis, active issue brief, previous public canon references, and any Vitor voice notes.
3. Inspect existing drafts before rewriting from scratch.

If the TheMindShift project root is missing, ask for it. Do not run this loop from memory alone.

## Loop Steps

1. Confirm that research direction is approved or that the task is only a bounded draft experiment.
2. Plan the issue spine across Cold Open, The Shift, Field Analysis, Build the Work, optional Field Note, The Shift Applied, and Your Move.
3. Draft in Vitor-aligned language with concrete stakes, lived operator texture, and non-generic claims.
4. Self-review for voice drift, weak thesis, overexplaining, fake authority, generic AI phrasing, missing source grounding, and em dash usage.
5. Revise the draft once before handback when the self-review finds fixable issues.
6. Prepare the draft review handback with known risks and exact questions for Vitor only where his voice or judgment is required.

## Hard Stops

- Stop before final voice approval.
- Stop before source package lock.
- Stop before publication, posting, emailing, contacting anyone, or changing external systems.

## Output

Return the draft artifact target, revised draft status, self-review notes, voice risks, blockers, and next review action.
