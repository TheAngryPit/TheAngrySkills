# TheMindShift Publishing Prep Loop

Use this skill to prepare a publication package for Vitor review. It organizes final assets and checks readiness, but it never publishes or final-locks the package.

TheMindShift project files and `TheAngry_Editor-inChief` remain authority. This skill is procedural support for a repeated editorial loop.

## Required Reads

1. Read TheMindShift `AGENTS.md`, `ACTIVE_STATE.md`, `CHECKPOINTS.md`, `NEWSLETTER_DOCTRINE.md`, and the active issue folder.
2. Read the approved draft, draft review decision, image or cover status, source links, and any platform formatting notes.
3. Inspect existing `publish-package.md` or publishing prep artifact before replacing it.

If the TheMindShift project root is missing, ask for it. Do not run this loop from memory alone.

## Loop Steps

1. Confirm draft approval status, image status, link status, and current human gate.
2. Assemble final text, metadata, platform formatting notes, source links, image references, and manual publish checklist.
3. Check no-em-dash compliance, unresolved comments, missing images, broken references, and any mismatch between draft and package.
4. Produce a publishing prep brief or package draft that clearly separates ready items from unresolved blockers.
5. Self-review for accidental external action, premature source lock, missing final image approval, and stale issue numbering.
6. Revise the package if the self-review finds fixable local issues, then hand back the exact Vitor approval needed.

## Hard Stops

- Stop before source package lock.
- Stop before final image approval or publication readiness approval.
- Stop before publication, posting, emailing, contacting anyone, or changing external systems.

## Output

Return the publish package target, readiness checklist, blockers, unresolved human approvals, and next manual action.
