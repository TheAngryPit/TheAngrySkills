# TheMindShift Skills

This project folder groups source-controlled TheMindShift skills.

The project folder is for repo organization. Codex and the skills CLI route by each skill's frontmatter `name`.

## Current Source Layout

- `loop-router/` contains `themindshift-loop-router`.
- `theme-approval-loop/` contains `themindshift-theme-approval-loop`.
- `research-synthesis-loop/` contains `themindshift-research-synthesis-loop`.
- `writer-loop/` contains `themindshift-writer-loop`.
- `editorial-review-loop/` contains `themindshift-editorial-review-loop`.
- `publishing-prep-loop/` contains `themindshift-publishing-prep-loop`.
- `repurpose-loop/` contains `themindshift-repurpose-loop`.

Future approved TheMindShift skills should live directly under `skills/knowledge/themindshift/<skill-folder>/`, not as unrelated top-level folders under `skills/knowledge/` and not inside another unnecessary layer.

## Implemented Skills

- `themindshift-loop-router`: route work to the next loop, gate, heartbeat, task, worker, or blocked state.
- `themindshift-theme-approval-loop`: prepare five reviewable theme options and a human approval surface.
- `themindshift-research-synthesis-loop`: synthesize research, source balance, and the deep research verdict.
- `themindshift-writer-loop`: draft or revise an issue from approved research while preserving Vitor voice.
- `themindshift-editorial-review-loop`: review thesis, voice, structure, evidence, taste, and no-em-dash compliance.
- `themindshift-publishing-prep-loop`: assemble the manual publish package and readiness brief.
- `themindshift-repurpose-loop`: create derivative assets only after final source package lock.

These skills are procedural loop supports. They are not the Editor-in-Chief and they are not project authority.

Project authority stays in the TheMindShift project files and the `TheAngry_Editor-inChief` manager thread.

## Rules

- Do not skillify `TheAngry_Editor-inChief` itself.
- Do not copy long project doctrine into this skill family.
- Keep project doctrine in TheMindShift project files.
- Do not publish, post, email, contact anyone, or alter external systems.
- Do not approve final theme, final voice fit, source package lock, final image approval, or publication readiness.
