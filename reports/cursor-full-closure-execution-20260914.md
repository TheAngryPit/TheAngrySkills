publication, native activation, global installation, and full source parity are

## Closure rule

For each active skill, read the pinned skill and all relative references,
preserve its trigger and output, map its exact native dependencies, and run at
least one bounded success and one relevant degraded/error path. Publish only
the branch whose behavior has actually been observed. An unavailable provider,
Canvas SDK, cloud tree, trusted hook, or model readback remains an explicit
capability result inside an otherwise useful conditional adapter; it does not
become an invented success. Retain each original scanner finding. Require
deterministic generator output, source/license provenance, explicit-only policy
where the source disables model invocation, baseline-comparative security
scan, public-safe diff, tests, and CI before PR review. No global install,
automation activation, external communication, or merge follows from a mirror.
