# Continual-learning native role fixture

The held `cursor-continual-learning` mirror bundles the pinned `agents-memory-updater` role. One bounded native delegate exercised that role on a synthetic, single-transcript project fixture. It could edit only the fixture's `AGENTS.md` and incremental index. No real transcript, global memory, project hook, or user workspace file was read or changed.

The transcript repeated the request to cite the exact source file before changing a dependency and contained a one-off lunch instruction. The delegate updated the existing preference bullet to the specific recurring rule, preserved an unrelated workspace-fact bullet, excluded the lunch instruction, and indexed only the supplied transcript at its observed mtime. A coordinator readback checked the exact `AGENTS.md` content and JSON index.

The source role did not define an index schema. The delegate inferred an absolute-transcript-path-to-`mtimeMs` map. The Codex overlay now fixes that schema for deterministic incremental processing and requires the current-workspace transcript boundary. This fixture proves one constrained role execution. It does not prove native trigger routing, real transcript parsing, modified/deleted transcript handling, stale-index pruning, hook trust, or suitability of a proposed `AGENTS.md` change in a real project.

A second bounded pass used the same unchanged transcript and index. The delegate returned `No high-signal memory updates.` and a coordinator compared both fixture files byte-for-byte: neither changed. This covers the unchanged-mtime no-op case, while modified and deleted transcript cases remain unproven.
