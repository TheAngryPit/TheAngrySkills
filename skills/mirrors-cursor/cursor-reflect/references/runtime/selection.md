# Select one execution contract

Keep the original skill directory as the base for relative paths in native-codex.md. That file preserves the original Codex contract verbatim; it is not a new runtime registration.

Choose from actual host context and exposed tools, not the model brand. In a verified T3 Code context with orchestrator_capabilities, read t3.md before executing runtime-dependent steps. A Codex model inside T3 still uses T3 task/worktree/PR ownership. Native same-provider delegation is allowed only within the current host instructions. If T3 tools are deferred, try the named capability tool once; absence is not a permission refusal.

Outside T3, if the host is native Codex, follow the inline native Codex branch unchanged. An explicitly selected unavailable context or an ambiguous host is blocked: do not infer another runtime from a filename, model name or citation. A refusal binds every branch; never fall through to a different tool, provider or host to perform the refused action.

Hermes, OpenClaw native subagents, OpenClaw native Codex embedding and OpenClaw ACP remain separate future contexts. These packages do not implement those runtimes. Report the missing adapter rather than treating ACP as a generic fallback.

Runtime guidance does not grant delegation, spending, scheduling, publication, installation or access. Preserve the operator's scope, repository ownership, model-capability-router policy and proof-orchestrator proof requirements. Installation, discovery, fixture tests, live execution and complete workflow proof are separate evidence levels.
