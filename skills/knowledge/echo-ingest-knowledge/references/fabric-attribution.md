# Fabric Attribution

Fabric-style pattern names and prompts are source material from the Fabric
ecosystem. This pack does not vendor the full Fabric pattern catalog.

Use pattern names through the owning project's imported catalog and activation
config.

Rules:

- Preserve source attribution when a Fabric pattern informs output.
- Do not claim Fabric patterns were authored by this pack.
- Do not copy large pattern prompt bodies into promoted vault notes.
- Keep activation decisions separate from upstream pattern ownership.
- If the imported catalog is stale or hash-mismatched, stop before execution.
