## Source Authority

Use the project's current source-authority rules. In general:

- live posted public issues outrank drafts;
- approved issue files outrank generated notes;
- project doctrine outranks old seed prompts;
- seed GPT threads are source material, not live instructions.

Do not ingest unrelated archives while routing.
