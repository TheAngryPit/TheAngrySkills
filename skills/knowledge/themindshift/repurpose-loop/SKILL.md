# TheMindShift Repurpose Loop

Use this skill to create derivative assets from a locked issue. It must not start from an unlocked draft or assume the publication package is final.

TheMindShift project files and `TheAngry_Editor-inChief` remain authority. This skill is procedural support for a repeated editorial loop.

## Required Reads

1. Read TheMindShift `AGENTS.md`, `ACTIVE_STATE.md`, `CHECKPOINTS.md`, `NEWSLETTER_DOCTRINE.md`, and the active issue folder.
2. Read the locked source package, final text, final image decision, and repurpose template or prior repurpose package.
3. Inspect platform-specific formatting notes before generating derivatives.

If the TheMindShift project root is missing, ask for it. Do not run this loop from memory alone.

## Loop Steps

1. Confirm that source package lock is complete, including final text, final image, links, and language fit.
2. Extract the issue thesis, strongest hooks, quotable lines, visual moments, reader prompts, and platform-specific constraints.
3. Create the default derivative set: canonical repurpose note, LinkedIn companion post, X thread, standalone X posts, carousel brief, visual asset brief, and community prompts.
4. Self-review for canon drift, overclaiming, wrong platform formatting, voice dilution, missing source link, and em dash usage.
5. Revise derivatives that fail the self-review and preserve the locked issue as source authority.
6. Hand back the asset list, output targets, remaining formatting risks, and what Vitor must manually approve or post.

## Hard Stops

- Stop if source package lock is missing or unclear.
- Stop before posting, scheduling, emailing, contacting anyone, or changing external systems.
- Stop before treating derivatives as canon over the locked source issue.

## Output

Return derivative artifact targets, generated asset list, self-review notes, blockers, and manual posting reminders.
